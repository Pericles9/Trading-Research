### Phase 10b close-out (2026-08-13)

- **Fragmentation-plateau check — never run, cheap, method stated.** Phase 10b T1 was specified but
  the phase stopped at its control gate before reaching it on the full cohort. Hypothesis: the
  sub-knee Allan plateau (height ~6 on controls) is execution fragmentation, and per event its
  height tracks the **size-weighted** mean sweep size E[N^2]/E[N], not the plain mean E[N]. Method:
  group each event's T=0 prints into maximal runs with inter-print gap <= 1e-4 s, regress log
  plateau height on log E[N^2]/E[N] across events, per segment; a slope near 1 against the
  size-weighted mean and below 1 against the plain mean confirms it. Code exists at
  `research/phase_10b/t1_plateau.py`. This is the cleanest available explanation of the plateau.
- **Global envelope test — blocked offline.** Myllymaki et al. (2017) JRSS-B 79:381-404. Requires
  >= 2,499 simulations for a single-curve test at the 5% level and an extreme-rank-length ordering
  to break rank ties. Blocked because this environment has no R, no `rpy2`, no maintained Python
  port, and no reachable package index (D14). Reviving it needs either a reference implementation to
  validate against or an offline validation route agreed at drafting time — a candidate triad is
  recorded in `prompts/phase_10b_amendment_2.md` A2-T5: single-rung reduction to the ordinary Monte
  Carlo rank p-value, p-value uniformity under the null across the whole range, and type I error on
  a true-null control.
- **Indirect inference — available, declined 2026-08-13.** Gourieroux, Monfort & Renault (1993),
  J. Appl. Econ. 8:S85-S118. A sharp biased statistic is a poor estimator but a good summary
  statistic: run simulated cluster processes through the identical biased pipeline and match
  outputs, so the bias cancels rather than needing correction. Consistency requires the binding
  function to be one-to-one, and **the finding that failed Phase 10b's usability criterion 3
  supports this** — C4 and C4' having different biases means the statistic is sensitive to scale
  separation, which is what makes the map invertible; a common bias would have made the
  configuration unidentifiable. Declined because it would be the sixth method family on this
  question, because the design side proposed continuing three times and authored eleven
  specification defects in the process, and because the cost stack rather than the burst timescale
  is the binding constraint on the scalping thesis and is measurable today (~33.6% of the excursion
  sits above the detection price on a median ~$3 stock). Recorded so a future revival starts from
  the argument rather than rediscovering it.
